Neon UI Kit Lite
================

Thanks for downloading! This Lite has 30 of the 218 pieces in Neon UI Kit.

THE FULL KIT ADDS
  - every piece in 3 color themes: Cyber, Vaporwave and Amber Terminal (new in v2.0)
  - keyboard, gamepad and mouse prompts, speech bubbles, banners, dropdowns,
    loading spinner, quest markers and a pixel font (new in v2.0)
  - more panels (4 sizes, dark panel, 9-slice panel, tooltip)
  - every button color with normal / hover / pressed states
  - radio, slider, scrollbar, tabs, portrait frame and more bars
  - more icons, stars, coins and pixel digits
  - ENGINE_SETUP.txt with Godot 4 and Unity steps
  - an RPG Maker MZ / MV windowskin (Window.png) in the kit's style
  - example screens (main menu and inventory)
  See FULL_KIT_PREVIEW.png in this zip.
